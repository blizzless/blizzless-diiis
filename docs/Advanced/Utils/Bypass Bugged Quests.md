## About

If a quest/step is marked with this document, it means it's **automatically advanced** if the option `BypassBuggedQuests` is true. See [[Known Bugs]] for more information.
## Configuration

On the `config.ini` there's a `BypassBuggedQuests` option in `[Game Server]` section.

It bypasses quests that are currently broken and the fix is still unknown (or suspected).

## Manually

You can bypass a step by using the `!quest advance` command.
