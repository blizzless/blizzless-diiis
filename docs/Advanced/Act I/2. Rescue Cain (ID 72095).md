## Overview
- **Objective**: Defeat monsters and rescue Deckard Cain back to **New Tristam**
- **Observed Interactions**:
  - Mostly showing navigation around the world with the waypoint and first level to kill monsters with an objective.
  - There's bugs all around Leah's object [^1] and must be aware of a bug on Cain's teleportation [^2].
